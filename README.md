# Minhaj Shaikh Blog

A professional personal blogging website built for a college web-development final assignment.

## Technologies
- HTML5
- CSS3
- JavaScript
- LocalStorage
- GitHub Pages

## Features
- Responsive modern design
- Home, About, Blog, Post and Contact pages
- Search and category filtering
- Login and Sign Up
- LocalStorage-based demo authentication
- Like and Save buttons
- Comment system
- Dark/Light theme
- Contact form validation
- Dynamic blog cards

## Run locally
Open `index.html` in a browser. For best results, use VS Code Live Server.

## GitHub Pages
1. Create a new GitHub repository.
2. Upload all project files.
3. Go to Settings → Pages.
4. Select the main branch and root folder.
5. Save and open the generated GitHub Pages URL.

## Important
The login system is for educational/demo purposes only. A production website should use a secure backend, database and password hashing.
